A reproducible pipeline that identifies friction torque at each joint of a 6-DoF Svaya Robotics collaborative arm using three complementary approaches — an analytical Coulomb–Viscous fit, a black-box neural network, and a physics-informed LuGre network. Data readiness per joint

Joints J1, J2, J3, J5 are modelled; J4 and J6 are excluded. Logs are sampled at 200 Hz from the Svaya control API.

Three friction-modelling approaches

Each model maps joint state (position q, velocity v) to the friction torque Tf, but from a different modelling philosophy. Together they trade interpretability against expressive power.

01

Modified Coulomb–Viscous

Closed-form analytical model fit by robust non-linear least squares (SciPy TRF, Huber loss). Fully interpretable — every parameter is a physical friction coefficient.

τf = Tc·tanh(veff/Vs) + Bv·veff + C0 veff = v + Cp·q
  • Tc — Coulomb torque
  • Bv — viscous coefficient
  • Vs — Stribeck velocity scale
02

Black-box Neural Network

A multilayer perceptron that learns the friction map directly from data with no physical prior. Captures asymmetries and non-linearities the analytical model cannot express.

[q, v] → Dense(64) → Dense(64) → Dense(32) → Tf ReLU activations · cycle-aware train/test split
  • Highest raw accuracy
  • No physical interpretation
  • Benchmark / upper bound
03

LuGre PINN

A physics-informed network that identifies the parameters of the dynamic LuGre friction model by embedding its steady-state law in the loss function — data-driven, yet physically grounded.

g(v) = Fc + (Fs−Fc)·e−(v/vs)² identifies σ₀, σ₁, σ₂, Fc, Fs, vs
  • Interpretable LuGre parameters
  • Physics-constrained fit
  • Best of both worlds
